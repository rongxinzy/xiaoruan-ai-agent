Heading 1: 知远 产品操作手册
Normal: 文档版本: v2026.7.16
Normal: 文档性质: 终端用户操作指南
Heading 2: 1. 产品概述
Normal: 知远 是一款本地优先的桌面 AI Agent 应用，运行于 Windows 平台。产品核心能力包括与 AI 智能体进行协作式对话、管理技能扩展、接入本地推理模型、配置 MCP 服务器组、创建定时自动化任务，以及集成即时通讯平台实现机器人响应。
Normal: 知远 的设计目标是为开发者和高级用户提供一个可控、可扩展的 AI Agent 工作环境。所有模型调用均通过用户自主配置的 API 密钥或本地推理引擎完成，数据不会上传至非用户指定的服务器。
Normal: 主要功能模块:
List Bullet: 协作工作台 (Cowork): 与 AI 智能体进行多会话对话，支持工具调用、权限控制、技能关联
List Bullet: 技能管理 (Skills): 浏览、安装、启用和创建扩展 Agent 能力的技能包
List Bullet: MCP 服务器组 (MCP Servers): 配置和管理 Model Context Protocol 服务器连接
List Bullet: 本地推理 (Local Inference): 通过 llama.cpp 引擎运行本地 AI 模型，支持模型市场下载
List Bullet: 预设专家 (Experts): 使用预设的专家 Agent 配置，快速启动特定领域的协作会话
List Bullet: 定时任务 (Scheduled Tasks): 创建基于模板的定时自动化任务
List Bullet: 即时通讯集成 (IM Bot): 将 Agent 接入微信、企业微信、飞书、钉钉、QQ 等即时通讯平台
List Bullet: 多模型支持: 支持 OpenAI、Anthropic、Google Gemini、DeepSeek、Moonshot、智谱、MiniMax、通义千问、千帆、小米、阶跃星辰、火山引擎、OpenRouter、llama.cpp、GitHub Copilot 等供应商

Heading 2: 5. 协作工作台 (Cowork)
Normal: 协作工作台是 知远 的核心功能模块，提供与 AI 智能体的多会话对话体验。
Heading 3: 5.1 工作模式
Normal: 协作工作台提供两种模式：
List Bullet: 工作模式 (Work): AI 智能体可调用工具（如读写文件、执行命令、搜索网页），适合完成编程、文件处理等任务。
List Bullet: 聊天模式 (Chat): AI 智能体仅进行文本对话，不调用工具，适合咨询、讨论等场景。
Normal: 模式切换入口位于 Cowork 视图内。
Heading 3: 5.2 会话操作
Normal: 创建会话:
List Bullet: 1. 进入 Cowork 视图。
List Bullet: 2. 在输入框中输入问题或指令。
List Bullet: 3. 可选操作：选择模型、关联技能。
List Bullet: 4. 按 Enter 或点击发送按钮开始对话。
Normal: 继续会话:
List Bullet: 在侧边栏会话列表中点击历史会话，即可继续之前的对话。
Normal: 会话内操作:
List Bullet: 模型选择: 在输入区域切换当前使用的 AI 模型。
List Bullet: 技能关联: 选择当前会话激活的技能。
List Bullet: 图片附件: 支持上传图片作为对话输入（需模型支持视觉功能）。
Heading 3: 5.3 工具权限控制
Normal: 当 AI 智能体需要执行工具操作时（如读取文件、执行命令、访问网络），系统将弹出权限确认对话框。用户可以选择：
List Bullet: 授权: 允许本次工具调用。
List Bullet: 拒绝: 拒绝本次工具调用。
List Bullet: 本次会话始终允许: 授权后不再弹出确认。
Heading 3: 5.4 快捷操作 (Quick Actions)
Normal: 协作工作台支持快捷操作功能，用户可以从预设的快捷操作列表中选择，快速发起特定类型的对话。
Heading 3: 5.5 引擎启动状态
Normal: OpenClaw 引擎启动过程中，协作工作台将显示引擎启动覆盖层，提示用户等待引擎就绪。引擎就绪后可正常开展对话。
Normal: 若引擎未就绪时尝试发送消息，系统将返回引擎未就绪的错误提示（错误代码: ENGINE_NOT_READY_CODE）。
Heading 3: 5.6 消息流式输出
Normal: AI 回复通过 SSE（Server-Sent Events）流式传输，消息内容实时增量渲染。流式传输过程中，用户可以观察 AI 的思考链（Reasoning）和工具调用结果。
Heading 2: 6. 技能管理 (Skills)
Heading 3: 6.1 技能概述
Normal: 技能（Skills）是 知远 的扩展机制。每个技能是一个独立的功能包，包含技能定义文件（SKILL.md）和附属资源（脚本、参考资料、资源文件等）。技能在协作会话中激活后，Agent 可根据技能定义执行特定的专业任务。
Heading 3: 6.2 技能管理界面
Normal: 在技能管理视图中，用户可以：
List Bullet: 浏览已安装技能: 查看当前系统中所有可用的技能列表。
List Bullet: 启用/禁用技能: 通过开关控制技能的激活状态。
List Bullet: 安装新技能: 从技能市场中搜索并安装新技能。
List Bullet: 删除技能: 移除不再需要的技能包。
List Bullet: 通过对话创建技能: 利用协作工作台的 AI 能力，以自然语言描述来创建新技能（触发方式：进入 Cowork 视图并预填充技能创建提示词）。
Heading 3: 6.3 技能安全扫描
Normal: 安装技能时，系统对技能包进行安全扫描，检查技能定义文件中的潜在风险。扫描机制确保技能不会执行未授权的操作或访问敏感资源。
Heading 3: 6.4 内置技能
Normal: 系统预装了多个内置技能，覆盖文档处理、数据分析、Office 套件等场景。具体清单参见 SKILLs/skills.config.json 配置文件。
Heading 2: 7. MCP 服务器组
Heading 3: 7.1 MCP 概述
Normal: Model Context Protocol (MCP) 是一种标准化协议，用于连接 AI 模型与外部工具和数据源。知远 支持用户配置 MCP 服务器组，使 Agent 能够访问数据库、API、文件系统等外部资源。
Heading 3: 7.2 MCP 服务器管理
Normal: 在 MCP 视图中，用户可以：
List Bullet: 添加 MCP 服务器: 配置服务器名称、连接方式、认证信息等参数。
List Bullet: 编辑服务器配置: 修改已有服务器的连接参数。
List Bullet: 启用/禁用服务器: 通过开关控制服务器的激活状态。
List Bullet: 连通性测试: 检测服务器连接是否正常。
List Bullet: 删除服务器: 移除不再需要的服务器配置。
Normal: MCP 配置数据持久化存储在 SQLite 数据库中，通过 McpStore 管理。
Heading 3: 7.3 桥接服务
Normal: 知远 内置 McpBridgeServer 组件，作为 Agent 引擎与 MCP 服务器的通信桥梁，负责协议转换和请求路由。
Heading 2: 8. 本地推理 (Local Inference)
Heading 3: 8.1 功能概述
Normal: 本地推理功能允许用户在本地计算机上运行 AI 模型，无需依赖云端 API。知远 通过集成 llama.cpp 引擎实现本地推理能力，支持多平台运行时。
Heading 3: 8.2 模型管理
Normal: 本地推理视图包含两个标签页：
Normal: 模型标签页:
List Bullet: 查看已安装的本地模型列表。
List Bullet: 启动模型：选择已安装的模型并启动 llama-server 子进程。
List Bullet: 配置模型参数：设置上下文窗口大小（Context Window）、GPU 加速等选项。
List Bullet: 查看模型启动日志。
List Bullet: 停止/卸载模型。
Normal: 市场标签页:
List Bullet: 浏览模型市场，搜索可下载的 AI 模型。
List Bullet: 下载新模型并实时查看下载/安装进度。
List Bullet: 模型筛选和排序。
Heading 3: 8.3 模型与Agent引擎的绑定
Normal: 运行中的 llama.cpp 模型将自动注册为Agent引擎的可用 Provider。系统评估模型是否满足最低上下文窗口要求后，将其暴露给协作工作台的模型选择器。
Heading 3: 8.4 后端管理
Normal: 本地推理子系统使用 LlamaCppBackendManager 管理底层 llama.cpp 后端配置，支持 CPU 和 GPU 推理模式的切换。
Heading 2: 9. 预设专家 (Experts)
Heading 3: 9.1 功能概述
Normal: 预设专家是预配置的 Agent 角色定义，为特定领域场景（如代码审查、文档撰写、数据分析）提供优化的 Agent 行为配置。用户可直接选用预设专家，无需手动调整 Agent 参数。
Heading 3: 9.2 界面组成
Normal: 专家视图是一个聚合界面，包含三个标签页：
List Bullet: 专家 (Experts): 展示预设专家列表，用户可选择专家并启动对应的协作会话。
List Bullet: 技能 (Skills): 复用技能管理界面，方便在同一视图中管理相关技能。
List Bullet: MCP (MCP Servers): 复用 MCP 管理界面，方便配置专家所需的工具链。
Heading 3: 9.3 使用方式
List Bullet: 1. 进入专家视图，浏览可用的预设专家列表。
List Bullet: 2. 点击选择目标专家，系统将自动配置 Agent 参数。
List Bullet: 3. 在关联的技能和 MCP 标签页中激活该专家所需的功能模块。
List Bullet: 4. 返回 Cowork 视图开始对话。
Heading 2: 10. 定时任务 (Scheduled Tasks)
Heading 3: 10.1 功能概述
Normal: 定时任务功能允许用户创建基于模板的自动化任务，按照预设的时间规则（如每天、每周）自动执行，无需人工干预。
Heading 3: 10.2 任务管理
Normal: 定时任务视图包含三个标签页：
Normal: 创建标签页:
List Bullet: 浏览任务模板画廊。
List Bullet: 选择模板并填写任务参数。
List Bullet: 配置执行时间规则（支持 RRULE 格式）。
List Bullet: 设置任务有效期（validFrom / validUntil）。
Normal: 任务标签页:
List Bullet: 查看已创建的任务列表。
List Bullet: 查看任务详情。
List Bullet: 编辑任务配置（含表单脏数据保护确认）。
List Bullet: 启用/暂停/删除任务。
List Bullet: 删除操作提供确认弹窗，防止误操作。
Normal: 历史标签页:
List Bullet: 查看所有任务的执行运行历史。
List Bullet: 每次执行记录包含执行时间、执行结果等信息。
Heading 3: 10.3 任务执行机制
Normal: 定时任务由主进程的调度引擎管理，任务定义和执行状态存储在 SQLite 数据库的 automations 和 automation_runtime_state 表中，执行历史记录在 automation_runs 表中。任务在指定时间触发时，知远 将启动OpenClaw会话执行任务指令。
Heading 2: 11. 即时通讯集成 (IM Bot)
Heading 3: 11.1 功能概述
Normal: IM Bot 功能允许将 知远 Agent 接入即时通讯平台，使 Agent 作为聊天机器人响应外部消息。当前支持企业微信、飞书、钉钉、微信、QQ 五个平台（中文语言环境下可见）。
Normal: 各平台的可见性受区域过滤机制控制。getVisibleIMPlatforms('zh') 仅返回 region: 'china' 的平台。
Heading 3: 11.2 平台配置入口
Normal: IM Bot 配置位于设置面板的「IM」标签页，而非主导航视图。配置路径：Settings > IM。
Heading 3: 11.3 配置流程
List Bullet: 1. 在 IM 设置标签页中选择目标平台（如企业微信）。
List Bullet: 2. 每个平台支持配置多个机器人实例（各平台有最大实例数限制）。
List Bullet: 3. 根据分步设置指南填写配置参数（应用 ID、密钥、回调地址等）。
List Bullet: 4. 运行连通性测试，查看 pass/warn/fail 级别的检测结果。
List Bullet: 5. 部分平台支持通过 QR 码扫码登录。
Heading 3: 11.4 消息处理链路
Normal: 当外部平台发送消息时：
List Bullet: 1. IM 连接器（OpenClaw 插件）接收消息并转发至主进程。
List Bullet: 2. IMGatewayManager 将消息路由至 imCoworkHandler。
List Bullet: 3. imCoworkHandler 创建或复用 Cowork 会话，将消息发送给 Agent 引擎。
List Bullet: 4. Agent 引擎处理消息并生成回复。
List Bullet: 5. 回复通过 imChatHandler 回传至对应的 IM 平台。

Heading 2: 13. 数据备份与恢复
Heading 3: 13.1 自动备份
Normal: 知远 将核心数据存储在本地 SQLite 数据库中，系统在初始化时自动执行备份恢复检查：
List Bullet: 数据库文件路径位于用户数据目录。
List Bullet: 若检测到主数据库文件损坏，自动从备份文件恢复。
Heading 3: 13.2 数据内容
Normal: 知远 本地存储的数据包括：
List Bullet: 会话数据: 协作会话记录和消息历史（cowork_sessions、cowork_messages 表）。
List Bullet: 配置数据: 用户设置（KV 键值存储）。
List Bullet: 技能配置: 技能启用状态和排序。
List Bullet: MCP 配置: MCP 服务器连接参数。
List Bullet: 定时任务: 任务定义和执行历史。
List Bullet: IM 配置: 各平台的机器人实例配置。
Heading 3: 13.3 手动备份
Normal: 用户可通过以下方式手动备份数据：
List Bullet: 1. 找到 知远 数据目录。
List Bullet: 2. 复制整个数据目录至备份位置。
List Bullet: 3. 恢复时将备份目录还原至原路径即可。
Heading 2: 14. 故障排查
Heading 3: 14.1 应用无法启动
Normal: 现象: 启动后显示初始化错误提示。
Normal: 排查步骤:
List Bullet: 1. 点击「重启应用」按钮重试。
List Bullet: 2. 若反复失败，点击「打开设置」检查配置是否正确。
List Bullet: 3. 检查系统是否满足最低硬件要求。
List Bullet: 4. Windows 平台确认已安装 PortableGit。
Heading 3: 14.2 Agent 引擎未就绪
Normal: 现象: 发送消息时提示引擎未就绪。
Normal: 排查步骤:
List Bullet: 1. 等待引擎启动覆盖层消失（首次启动可能需要较长时间）。
List Bullet: 2. 进入 Settings > Agent Engine 查看引擎安装/运行状态。
List Bullet: 3. 若引擎状态异常，尝试重启应用。
Heading 3: 14.3 模型连接失败
Normal: 现象: 对话无法正常回复，提示连接错误。
Normal: 排查步骤:
List Bullet: 1. 进入 Settings > Model，检查供应商 API 密钥是否填写正确。
List Bullet: 2. 使用「连接测试」功能验证供应商 API 的连通性。
List Bullet: 3. 检查网络连接和防火墙设置。
Heading 3: 14.4 本地模型运行异常
Normal: 现象: 本地推理模型无法启动或推理异常。
Normal: 排查步骤:
List Bullet: 1. 检查系统是否满足模型的硬件要求（显存/内存）。
List Bullet: 2. 查看模型启动日志中的错误信息。
List Bullet: 3. 确认 llama.cpp 后端平台选择正确（CPU/GPU）。
List Bullet: 4. 尝试降低上下文窗口大小。
Heading 3: 14.5 IM Bot 连接失败
Normal: 现象: 连通性测试未通过。
Normal: 排查步骤:
List Bullet: 1. 核对平台提供的配置参数是否正确。
List Bullet: 2. 检查网络防火墙是否允许对外连接。
List Bullet: 3. 确认回调地址可被 IM 平台服务器访问。
List Bullet: 4. 重新进行扫码登录。
