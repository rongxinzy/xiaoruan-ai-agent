Heading 2: 2. 产品定位与技术理念
Heading 3: 2.1 产品定位
Normal: 知远 定位于专业的 AI Agent 桌面工作站，区别于通用聊天类 AI 应用，它提供以下核心价值：
List Bullet: 可控性: 用户自主选择 AI 模型供应商，可完全使用本地模型，数据不出本地。
List Bullet: 可扩展性: 通过技能（Skills）、MCP 协议、自定义供应商实现能力扩展。
List Bullet: 工具化: Agent 可调用系统工具（文件读写、终端命令、网络请求），完成实际的工程任务。
List Bullet: 多平台覆盖: 同时支持桌面端 Agent 交互和即时通讯端机器人响应。
Heading 3: 2.2 技术理念
List Bullet: 进程隔离: 每个外部推理引擎（OpenClaw Gateway、llama.cpp llama-server）作为独立子进程运行，故障隔离。
List Bullet: 本地优先: 核心数据（配置、会话、模型参数）均存储在本地 SQLite 数据库，云端仅用于模型 API 调用。
List Bullet: 文档即代码: 代码与文档同步发布，关键功能必有对应文档覆盖。
List Bullet: 开放标准: 采用 OpenAPI、MCP、RRULE 等开放标准，确保互操作性。

Normal: 安全隔离措施:
List Bullet: contextIsolation: true：渲染进程无权直接访问 Node.js API。
List Bullet: nodeIntegration: false：禁用 Node.js 集成。
List Bullet: webSecurity: true：同源策略生效，阻止跨域请求。

Heading 3: 4.2 OpenClaw Gateway
Normal: OpenClaw 是 知远 的 Agent 运行时引擎，负责 IM 会话和 Cron 定时任务：
List Bullet: 运行方式: 作为独立 Node.js 子进程运行，与主进程通过 HTTP API 通信。
List Bullet: 生命周期管理: OpenClawEngineManager 管理安装（从源码构建）、启动、状态监控、崩溃重启。
List Bullet: 状态机: not_installed --> ready --> starting --> running | error
List Bullet: 配置同步: OpenClawConfigSync 将 Cowork 配置（模型供应商、认证凭证等）同步为 OpenClaw 配置文件。
List Bullet: 插件体系: 通过 OpenClaw 插件（企业微信、飞书、钉钉、微信连接器）实现 IM 集成。
List Bullet: 本地扩展: 支持加载 openclaw-extensions/ 目录下的本地扩展模块。
Heading 3: 4.3 Agent 引擎路由
Normal: CoworkEngineRouter 是 Agent 调度的核心路由模块，位于 src/main/libs/agentEngine/coworkEngineRouter.ts。它实现：
List Bullet: 引擎分发: 将 Cowork 会话请求路由到活跃的引擎适配器（OpenClawRuntimeAdapter）。
List Bullet: 流事件转发: 将引擎产生的流事件（消息增量、工具调用、思考链）转发至渲染进程的 IPC 监听器。
List Bullet: 权限拦截: 当引擎请求工具执行时，生成 permissionRequest 事件，暂停执行等待用户确认。

List Bullet: 1. 读取技能定义文件（SKILL.md）。

Heading 3: 6.5 网络安全
List Bullet: 所有对外 API 通信使用 HTTPS。
List Bullet: 支持用户自定义代理配置。
List Bullet: 网络状态监控，离线时主动通知渲染进程。
List Bullet: 区域过滤机制，根据语言设置自动筛选可见的第三方平台。
Heading 2: 7. 性能特性
Heading 3: 7.1 流式响应
List Bullet: 所有 AI 对话采用 SSE（Server-Sent Events）流式传输。
List Bullet: 消息内容实时增量渲染，首字符响应时间（TTFB）依赖模型供应商性能。
List Bullet: 本地模型推理延迟取决于硬件配置（GPU 型号、显存大小）。
Heading 3: 7.2 会话管理性能
List Bullet: 会话列表支持分页加载（COWORK_SESSION_PAGE_SIZE）。
List Bullet: 使用 SQLite 索引优化会话查询。
List Bullet: 应用启动时采用并发初始化策略（Promise.all 并行加载多个子系统）。
Heading 3: 7.3 内存占用
List Bullet: 基础应用运行时内存占用约 300-500 MB（Electron + React）。
List Bullet: 运行本地模型时额外内存占用取决于模型大小（如 7B 参数量化模型约需 4-8 GB）。
List Bullet: 长会话历史存储在 SQLite 中，不占用内存。
Heading 3: 7.4 启动性能
List Bullet: 冷启动设置了 24 秒超时保护。
List Bullet: 初始化阶段有详细的性能标记日志（performance.now()），便于诊断启动瓶颈。

Heading 2: 13. 版本与兼容性策略
Heading 3: 13.1 版本号规范
Normal: 采用语义化版本号 (Semantic Versioning)：
List Bullet: 主版本号 (MAJOR): 不兼容的 API 变更。
List Bullet: 次版本号 (MINOR): 向后兼容的功能新增。
List Bullet: 修订号 (PATCH): 向后兼容的问题修复。
Heading 3: 13.2 向后兼容性
List Bullet: 配置文件格式保持向后兼容，新增字段提供默认值。
List Bullet: 会话数据格式变更时提供自动迁移逻辑。
List Bullet: 技能包规范版本化，旧版技能在新版应用中继续可用。
List Bullet: 已有 IPC 通道不会变更或移除，仅新增通道。
Heading 3: 13.3 废弃策略
List Bullet: 废弃旧版 API 时提供至少一个次版本的过渡期。
List Bullet: 过渡期内同时支持新旧接口，并在设置面板中显示升级提示。
List Bullet: 废弃功能在文档中标注 @deprecated 及移除时间节点。
