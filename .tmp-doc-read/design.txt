Heading 2: 1. 系统概述
Heading 3: 1.1 产品定位
Normal: 知远 是一款基于 Electron 框架构建的桌面端人工智能助手应用，支持本地优先的 AI Agent 工作流。系统整合了本地大语言模型推理能力（通过 llama.cpp）、云端模型 API 接入、以及多渠道即时通讯网关，为用户提供统一的 AI 协作体验。
Heading 3: 1.2 核心技术栈
Heading 3: 1.3 系统边界
Normal: 本系统运行于用户本地桌面环境，其核心职责包括：
List Bullet: 1. 接收用户自然语言输入，通过 Agent 引擎执行任务编排与工具调用。
List Bullet: 2. 管理本地大语言模型的生命周期（下载、安装、启动、推理）。
List Bullet: 3. 通过 MCP (Model Context Protocol) 协议接入外部工具与数据源。
List Bullet: 4. 实现多渠道 IM 网关（企业微信、钉钉、飞书、微信、QQ等），使 Agent 可作为聊天机器人响应外部消息。
List Bullet: 5. 提供技能（Skill）市场与本地技能管理，扩展 Agent 能力边界。
List Bullet: 6. 支持定时任务的创建、管理与调度执行。

Heading 3: 7.2 Pi Runtime Adapter (piRuntimeAdapter.ts)
Normal: Pi 负责 Work 会话（用户在工作台 UI 中主动发起的协作对话），约 59KB 实现文件。cowork:session:start IPC 处理器直接调用 getPiRuntimeAdapter() 启动会话（main.ts:3359），无需等待 OpenClaw Gateway。
Normal: 技术实现：
List Bullet: 运行方式: 直接导入 @earendil-works/pi-coding-agent 和 @earendil-works/pi-ai 包，在 Node.js 主进程中运行，无子进程开销。
List Bullet: 会话创建: 通过 createAgentSession() 创建 AgentSession 实例，session.subscribe() 注册事件监听。
List Bullet: 流式输出: 支持 text_delta / thinking_delta 粒度的增量事件，分别映射到 UI 的回答气泡和思考气泡。
List Bullet: 模型支持: 支持本地 Provider（llama.cpp）和全部云端 Provider。
List Bullet: 会话状态: 维护 ActivePiSession 结构，包含 assistantMessageId、thinkingMessageId、answerText、thinkingText 等状态字段。
List Bullet: 工具调用: 完整追踪 tool_execution_start / tool_execution_update / tool_execution_end 事件链。
List Bullet: 权限模型: 支持 modal 模式（弹窗确认）和 text 模式（文本确认）。
Heading 3: 7.3 OpenClaw Runtime Adapter (openclawRuntimeAdapter.ts)
Normal: OpenClaw 负责 IM 会话（企业微信、飞书、钉钉、微信等平台消息驱动的对话）和 Cron 任务（定时任务调度执行），约 240KB 实现文件。其架构特点：
List Bullet: 运行方式: OpenClaw Gateway 作为独立子进程运行（UtilityProcess），通过 WebSocket 与主进程通信。
List Bullet: 引擎管理: OpenClawEngineManager 管理 Gateway 子进程生命周期，状态包括：not_installed -> installing -> ready -> starting -> compiling -> running -> error。
List Bullet: Gateway 端口: 默认端口 18789，启动时自动扫描可用端口（扫描范围 80 个端口）。
List Bullet: 启动超时: 冷启动 600 秒（含 V8 编译），预热启动 300 秒。
List Bullet: 重启策略: 最多 5 次重试，延迟递增（3s -> 5s -> 10s -> 20s -> 30s）。
List Bullet: Channel Session: 基于 OpenClawChannelSessionSync 的 channel session 机制，通过 buildManagedSessionKey 映射会话标识，实现 IM 平台 ↔ Session 绑定。
List Bullet: 消息流: 通过 Gateway 的 WebSocket 事件流接收 Agent 消息、工具调用、权限请求等。
List Bullet: 权限模型: 支持 modal 模式（弹窗确认）和 text 模式（文本确认）。
Normal: OpenClaw 插件体系（配置于 package.json 中）：
