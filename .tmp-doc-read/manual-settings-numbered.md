# 晓软智能体 产品操作手册

文档版本: v2026.7.16

文档性质: 终端用户操作指南

## 1. 产品概述

**晓软智能体**是面向本地工作流的桌面 `AI Agent` 应用。当前定制版提供协作工作台、技能、MCP、专家、定时任务和消息渠道能力；模型调用必须经过用户绑定的 `AISphere` 平台。

当前版本不提供产品账号登录、内置免费模型或第三方模型供应商入口。用户在设置中填写交付方提供的 `AISphere` 地址，使用平台返回的可用模型；模型凭据由主进程管理。

主要功能模块:

- 协作工作台 (Cowork): 与 AI 智能体进行多会话对话，支持工具调用、权限控制、技能关联；
- 技能管理 (Skills): 浏览、安装、启用和新建扩展 Agent 能力的技能包；
- MCP 服务器组 (MCP Servers): 配置和管理 Model Context Protocol 服务器连接；
- 模型来源: 通过绑定 `AISphere` 来获取平台模型；当前定制版本不支持第三方供应商、自定义模型或本地模型；
- 预设专家 (Experts): 使用预设的专家 Agent 配置，快速启动特定领域的协作会话；
- 定时任务 (Scheduled Tasks): 创建基于模板的定时自动化任务；
- 即时通讯集成 (IM Bot): 将 Agent 接入微信、企业微信、飞书、钉钉、QQ 等即时通讯平台；
- 模型目录: 已绑定的 `AISphere` 平台返回模型目录。该平台下架或连接失败时不会自动替换模型；
## 2. 安装与启动

### 2.1 系统要求

| 项目 | 最低要求 | 推荐配置 |
| --- | --- | --- |
| 操作系统 | Windows 10+ | Windows 11 |
| 内存 | 8 GB | 16 GB+ |
| 磁盘空间 | 2 GB (应用本体) | 10 GB+ |
| Node.js | >=24 <25 (仅开发构建需要) | - |
| 网络 | 宽带互联网连接 | - |

### 2.2 安装流程

Windows 平台

- 从官方发布渠道获取 晓软智能体-Setup-x.x.x.exe 安装包。
- 双击安装包，按照安装向导提示完成安装。
- 安装完成后，桌面和开始菜单将出现 晓软智能体 快捷方式。
- Windows 用户需确保系统已安装 PortableGit（参见 README.md 中的环境准备说明）。
### 2.3 首次启动

首次启动 晓软智能体 时，应用将执行以下初始化操作：

- 加载用户配置信息和国际化语言包。
- 解析可用模型列表并设置默认模型。
- 初始化Agent 运行引擎。
- 加载技能清单。

应用启动时间因网络环境而异。若启动超时或出现异常，应用将显示错误提示并提供「重启应用」和「打开设置」两个操作入口。

侧边栏中部提供**会话管理栏**，其可以细分为**五个主要导航项**和**会话管理栏**：

侧边栏底部设有：

- **设置按钮**，打开设置面板。

| --- | --- |

## 4. 协作工作台 (Cowork)

协作工作台是 **晓软智能体** 的核心功能模块，提供与 AI 智能体的多会话对话功能。

### 4.1 工作模式

协作工作台提供两种模式：

- **工作模式 (Work)**: AI 智能体可调用工具（如读写文件、执行命令、搜索网页），适合完成编程、文件处理等任务。
- **聊天模式 (Chat)**: AI 智能体仅进行文本对话，不调用工具，适合咨询、讨论等场景。

模式切换入口位于侧边栏顶部。

### 4.2 会话操作

**创建会话操作**:

- 进入协同工作台视图；
- 在输入框中输入问题或指令；
- 可选操作：选择模型、关联技能；
- 按 Enter 或点击发送按钮开始对话。

**继续会话操作**:

- 在侧边栏会话列表中点击历史会话，即可继续之前的对话。


**会话内操作**:

- 模型选择: 在输入区域切换当前使用的 AI 模型。
- 技能关联: 选择当前会话激活的技能。
- 图片附件: 支持上传图片作为对话输入（需模型支持视觉功能）。

### 4.3 工具权限控制

当 **晓软智能体** 需要执行工具操作时（如读取文件、执行命令、访问网络），系统将弹出权限确认对话框。用户可以选择：

- **授权**: 允许本次工具调用；
- **拒绝**: 拒绝本次工具调用；
- **本次会话始终允许**: 授权后不再弹出确认。
### 4.4 快捷操作 (Quick Actions)

协作工作台支持快捷操作功能，用户可以从预设的快捷操作列表中选择，以快速发起特定类型的对话。

### 4.5 引擎启动状态

应用启动时会初始化模型网关。请先在“设置”中连接 AISphere 并选择平台模型；在网关尚未就绪前发送消息，系统会提示连接或模型不可用。

### 4.6 消息流式输出

AI 回复的信息通过应用内流式通道实时传输，并在主内容区增量渲染。

## 5. 技能管理 (Skills)

### 5.1 技能概述

技能（Skills）是 **晓软智能体** 的扩展机制。每个技能都是一个独立的功能包，其包含技能定义文件（SKILL.md）和附属资源（脚本、参考资料、资源文件等）。技能在协作会话中激活后，Agent 可根据技能定义来执行特定的任务。

### 5.2 技能管理界面

在技能管理视图中，用户可以：

- **浏览已安装技能**: 查看当前系统中所有可用的技能列表。
- **启用/禁用技能**: 通过开关控制技能的激活状态。
- **安装新技能**: 从技能市场中搜索并安装新技能。
- **删除技能**: 移除不再需要的技能包。
- **通过对话创建技能**: 利用协作工作台的 AI 能力，以自然语言描述来创建新技能（触发方式：进入协同工作台视图并预填充技能创建提示词）。
### 5.3 技能安全扫描

安装技能时，**晓软智能体**会对技能包执行安全扫描，识别技能定义文件及相关资源中的潜在风险，降低未经授权的操作或敏感资源访问风险。

### 5.4 内置技能

系统预装了多个内置技能，覆盖文档处理、数据分析、Office 套件等场景。具体清单参见 SKILLs/skills.config.json 配置文件。

## 6. MCP 服务器组

### 6.1 MCP 概述

Model Context Protocol (MCP) 是一种标准化协议，用于连接 AI 模型与外部工具和数据源。晓软智能体 支持用户配置 MCP 服务器组，使 Agent 能够访问数据库、API、文件系统等外部资源。

### 6.2 MCP 服务器管理

在 MCP 视图中，用户可以：

- 添加 MCP 服务器: 配置服务器名称、连接方式、认证信息等参数。
- 编辑服务器配置: 修改已有服务器的连接参数。
- 启用/禁用服务器: 通过开关控制服务器的激活状态。
- 连通性测试: 检测服务器连接是否正常。
- 删除服务器: 移除不再需要的服务器配置。
MCP 配置数据持久化存储在 SQLite 数据库中，通过 McpStore 管理。

### 6.3 桥接服务

晓软智能体 内置 McpBridgeServer 组件，作为 Agent 引擎与 MCP 服务器的通信桥梁，负责协议转换和请求路由。

## 7. 本地推理 (Local Inference)

### 7.1 功能概述

当前定制版保留本地推理相关内部组件，但不向用户开放本地模型入口。内置模型请求仅使用已绑定 AISphere 平台返回的模型。

### 7.2 模型管理

本地推理页面不属于当前定制版的用户模型配置流程；请在设置 → 模型中管理 AISphere 绑定。

模型标签页:

- 查看已安装的本地模型列表。
- 启动模型：选择已安装的模型并启动 llama-server 子进程。
- 配置模型参数：设置上下文窗口大小（Context Window）、GPU 加速等选项。
- 查看模型启动日志。
- 停止/卸载模型。
市场标签页:

- 浏览模型市场，搜索可下载的 AI 模型。
- 下载新模型并实时查看下载/安装进度。
- 模型筛选和排序。
### 7.3 模型与Agent引擎的绑定

运行中的 本地推理组件 模型将自动注册为Agent引擎的可用 Provider。系统评估模型是否满足最低上下文窗口要求后，将其暴露给协作工作台的模型选择器。

### 7.4 后端管理

本地推理子系统使用 LlamaCppBackendManager 管理底层 本地推理组件 后端配置，支持 CPU 和 GPU 推理模式的切换。

## 8. 预设专家 (Experts)

### 8.1 功能概述

预设专家是预配置的 Agent 角色定义，为特定领域场景（如代码审查、文档撰写、数据分析）提供优化的 Agent 行为配置。用户可直接选用预设专家，无需手动调整 Agent 参数。

### 8.2 界面组成

专家视图是一个聚合界面，包含三个标签页：

- 专家 (Experts): 展示预设专家列表，用户可选择专家并启动对应的协作会话。
- 技能 (Skills): 复用技能管理界面，方便在同一视图中管理相关技能。
- MCP (MCP Servers): 复用 MCP 管理界面，方便配置专家所需的工具链。
### 8.3 使用方式

- 1. 进入专家视图，浏览可用的预设专家列表。
- 2. 点击选择目标专家，系统将自动配置 Agent 参数。
- 3. 在关联的技能和 MCP 标签页中激活该专家所需的功能模块。
- 4. 返回 Cowork 视图开始对话。
## 9. 定时任务 (Scheduled Tasks)

### 9.1 功能概述

定时任务功能允许用户创建基于模板的自动化任务，按照预设的时间规则（如每天、每周）自动执行，无需人工干预。

### 9.2 任务管理

定时任务视图包含三个标签页：

创建标签页:

- 浏览任务模板画廊。
- 选择模板并填写任务参数。
- 配置执行时间规则（支持 RRULE 格式）。
- 设置任务有效期（validFrom / validUntil）。
任务标签页:

- 查看已创建的任务列表。
- 查看任务详情。
- 编辑任务配置（含表单脏数据保护确认）。
- 启用/暂停/删除任务。
- 删除操作提供确认弹窗，防止误操作。
历史标签页:

- 查看所有任务的执行运行历史。
- 每次执行记录包含执行时间、执行结果等信息。
### 9.3 任务执行机制

定时任务由主进程的调度引擎管理，任务定义和执行状态存储在 SQLite 数据库的 automations 和 automation_runtime_state 表中，执行历史记录在 automation_runs 表中。任务在指定时间触发时，晓软智能体 将启动统一 Agent 运行时会话执行任务指令。

## 10. 即时通讯集成 (IM Bot)

### 10.1 功能概述

IM Bot 功能允许将 晓软智能体 Agent 接入即时通讯平台，使 Agent 作为聊天机器人响应外部消息。当前支持企业微信、飞书、钉钉、微信、QQ 五个平台（中文语言环境下可见）。

各平台的可见性受区域过滤机制控制。getVisibleIMPlatforms('zh') 仅返回 region: 'china' 的平台。

### 10.2 平台配置入口

IM Bot 配置位于设置面板的「IM」标签页，而非主导航视图。配置路径：Settings > IM。

### 10.3 配置流程

- 1. 在 IM 设置标签页中选择目标平台（如企业微信）。
- 2. 每个平台支持配置多个机器人实例（各平台有最大实例数限制）。
- 3. 根据分步设置指南填写配置参数（应用 ID、密钥、回调地址等）。
- 4. 运行连通性测试，查看 pass/warn/fail 级别的检测结果。
- 5. 部分平台支持通过 QR 码扫码登录。
### 10.4 消息处理链路

当外部平台发送消息时：

- 1. IM 连接器（渠道连接器）接收消息并转发至主进程。
- 2. IMGatewayManager 将消息路由至 imCoworkHandler。
- 3. imCoworkHandler 创建或复用 Cowork 会话，将消息发送给 Agent 引擎。
- 4. Agent 引擎处理消息并生成回复。
- 5. 回复通过 imChatHandler 回传至对应的 IM 平台。
## 11. 设置面板

### 11.1 设置面板概述

设置面板是一个模态浮层，覆盖在主界面上方。面板包含左侧标签页导航和右侧内容区域。设置更改即时生效，关闭面板时自动刷新模型列表。

### 11.2 设置标签页

#### 11.2.1 常规 (General)

- 基础应用设置。
- 语言切换（支持中文、英文等多语言）。
#### 11.2.2 外观 (Appearance)

- 主题切换：浅色模式 (Light)、深色模式 (Dark)、跟随系统 (System)。
- 三种模式均提供可视化预览卡片。
#### 11.2.3 模型 (Model)

- AISphere 绑定：填写平台根地址，连接并获取平台返回的模型目录。
- 模型选择：只能选择当前 AISphere 平台返回的模型。
- 模型目录：连接或刷新 AISphere 后查看可用模型；运行中的任务期间不能切换平台地址。
- 连接状态：显示 AISphere 是否可用；连接失败时清空可用模型并允许重试。
- 平台限制：平台地址仅支持 HTTP/HTTPS 根地址，模型请求通过应用内网关转发。
- 默认模型选择：设置默认使用的 AI 模型。
#### 11.2.4 即时通讯 (IM)

- 各平台机器人实例配置。
- 连通性测试。
- 实例数量上限管理。
#### 11.2.5 邮件 (Email)

- 配置邮件技能（IMAP/SMTP 参数），供技能使用。
#### 11.2.6 记忆管理 (Memory)

- 查看和管理 Agent 的持久化记忆条目。
- 支持添加、编辑、删除用户级记忆。
- 记忆以文件形式存储在 应用工作区中（MEMORY.md / memory/）。
#### 11.2.7 快捷键 (Shortcuts)

- 查看和自定义全局快捷键。
- 每个快捷键支持多键位组合。
#### 11.2.8 关于 (About)

- 应用版本号显示。
- 运行环境信息。
## 12. 数据备份与恢复

### 12.1 自动备份

晓软智能体 将核心数据存储在本地 SQLite 数据库中，系统在初始化时自动执行备份恢复检查：

- 数据库文件路径位于用户数据目录。
- 若检测到主数据库文件损坏，自动从备份文件恢复。
### 12.2 数据内容

晓软智能体 本地存储的数据包括：

- 会话数据: 协作会话记录和消息历史（cowork_sessions、cowork_messages 表）。
- 配置数据: 用户设置（KV 键值存储）。
- 技能配置: 技能启用状态和排序。
- MCP 配置: MCP 服务器连接参数。
- 定时任务: 任务定义和执行历史。
- IM 配置: 各平台的机器人实例配置。
### 12.3 手动备份

用户可通过以下方式手动备份数据：

- 1. 找到 晓软智能体 数据目录。
- 2. 复制整个数据目录至备份位置。
- 3. 恢复时将备份目录还原至原路径即可。
## 13. 故障排查

### 13.1 应用无法启动

现象: 启动后显示初始化错误提示。

排查步骤:

- 1. 点击「重启应用」按钮重试。
- 2. 若反复失败，点击「打开设置」检查配置是否正确。
- 3. 检查系统是否满足最低硬件要求。
- 4. Windows 平台确认已安装 PortableGit。
### 13.2 Agent 引擎未就绪

现象: 发送消息时提示引擎未就绪。

排查步骤:

- 1. 等待引擎启动覆盖层消失（首次启动可能需要较长时间）。
- 2. 进入 Settings > Agent Engine 查看引擎安装/运行状态。
- 3. 若引擎状态异常，尝试重启应用。
### 13.3 模型连接失败

现象: 对话无法正常回复，提示连接错误。

排查步骤:

- 检查 AISphere 地址、网络连接和平台模型目录。
- 点击「连接并获取模型」或「刷新模型」重试。
- 3. 检查网络连接和防火墙设置。
### 13.4 模型来源或平台连接异常

现象: 本地推理模型无法启动或推理异常。

排查步骤:

- 1. 检查系统是否满足模型的硬件要求（显存/内存）。
- 2. 查看模型启动日志中的错误信息。
- 3. 确认 本地推理组件 后端平台选择正确（CPU/GPU）。
- 4. 尝试降低上下文窗口大小。
### 13.5 IM Bot 连接失败

现象: 连通性测试未通过。

排查步骤:

- 1. 核对平台提供的配置参数是否正确。
- 2. 检查网络防火墙是否允许对外连接。
- 3. 确认回调地址可被 IM 平台服务器访问。
- 4. 重新进行扫码登录。
### 13.6 获取技术支持

如上述步骤无法解决问题，可通过以下渠道获取帮助：

- 查阅项目 GitHub 仓库的 Issue 列表。
- 通过设置面板的「关于」标签页查看运行环境信息，提供完整的错误描述和复现步骤。
## 14. 编程工作台

编程工作台面向代码任务提供工作区、任务、泳道和 Agent 协作管理。它与普通 Cowork 会话分开保存，可在同一工作区中组织多个任务和执行泳道。

内置编程 Agent 使用应用当前可用模型和权限策略；用户也可以发现并接入本机已安装且受信任的外部编程 Agent。外部 Agent 保留自己的账号、模型和配置，应用不会向其注入 AISphere 凭据。

- 创建或选择工作区，指定代码目录。
- 创建任务并准备执行泳道，可配置 Agent、模型覆盖和可用命令。
- 开始任务前查看权限请求；需要时暂停、取消、继续或恢复会话。
- 查看工作区文件、Git 状态和差异，并执行暂存、提交、分支切换和拉取请求操作。
- 通过交接和协作预设在不同 Agent 或泳道之间传递任务上下文。
